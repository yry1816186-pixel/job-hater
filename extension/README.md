# Job Hater 浏览器助手（Chrome / Edge，Manifest V3）

把任意网页的岗位描述（JD）一键存进**本机** Job Hater；在网申表单页一键填充基础信息。

## 安装（无需上架商店，本地加载）

1. 启动本机服务：`job-hater serve`（默认 `http://127.0.0.1:8787`）
2. Chrome 打开 `chrome://extensions`（Edge 打开 `edge://extensions`）
3. 打开右上角「开发者模式」→「加载已解压的扩展程序」→ 选择本 `extension/` 目录
4. 工具栏出现 Job Hater 图标即安装成功

## 功能

### 📄 抓取本页为 JD 草稿
在任何招聘页（公司官网 / 招聘平台 / 牛客帖 / 任何网页）点图标 →「抓取本页为 JD 草稿」：
自动识别主内容区文本 + 页面标题 + 公司名，弹窗内**可编辑**标题/公司/城市后入库
（走与 Web 端「导入岗位」完全相同的 `/api/jobs/import` 入口，享受同一套去重与解析）。

### ✍️ 填写本页表单（永不自动提交）
在企业网申表单页点「填写本页表单」：按画像填充 姓名/手机/邮箱/学校/学历/专业/毕业时间
等基础字段（支持下拉选项匹配），**所有已填充字段橙框高亮**，提交前请逐一核对。
**本扩展永不代你提交**——这是刻意设计（避免代投翻车与合规风险）。

## 隐私声明（与主程序同一立场）

- 扩展**只与本机 Job Hater 服务通信**（默认 `127.0.0.1:8787`，可在弹窗设置里改）；
  没有任何第三方服务器、没有统计上报、没有云端账号。
- 页面内容只在「你点击抓取」时读取一次，发给本机 API 入库，不经过任何中间层。
- 权限最小化：`activeTab`（仅活动标签页）+ `scripting`（按需注入）+ `storage`（记住设置）。
- 表单填充只写可见输入框并高亮，不触发提交、不读取密码框/文件框。

## 已知边界（如实说明）

- 抓取对结构化招聘页效果最好；内容区识别是启发式，抓错时手动改草稿字段即可。
- 填表覆盖中国网申常见基础字段；开放题、测评、验证码**不填也不该填**。
- 复杂 ATS（Workday 类多段经历循环块）暂不支持，规划中。
