# Profile Manager — 用户画像维护

## 命令

```bash
python3 core/cli.py profile --validate --show   # 校验 + 摘要
```

## 工作流程

### 1. 导入新材料（PDF/Word/文本）

用户给新材料（简历、成绩单、作品集、获奖证书）时：
1. 把原始文件复制到 `data/profile/raw/`（保留原件，永不修改）；
2. 逐条提取**事实**：教育、经历、技能、奖项、量化数据；
3. 更新 `data/profile/profile.json` 对应区块；
4. **每条新事实必须同时在 `evidence_index` 增加或更新锚点**（写明出处文件与原文关键句）；
5. 运行 `profile --validate` 确认所有技能/经历引用的证据ID存在；
6. 向用户展示"本次新增事实清单"，逐条确认。

### 2. 事实回写铁律（来自 ai-job-search 的 Standing Rule，已验证的最佳实践）

对话中用户随口确认的新事实（"那个项目其实是我独立完成的""我还有一段实习"）：
**必须在同一轮写回 profile.json + evidence_index**，并告知用户已记录。
原因：只存在于对话里的事实，下次会话生成简历时会被 factcheck 当作无证据主张删除。
这是输入端与审核端配合的机制，不是繁琐流程。

### 3. 更新的连锁反应

画像更新后提醒用户：
- 重新 `search`（评分结果可能变化）；
- 已生成但未投递的简历建议重新 `apply` 生成。

### 4. 禁止事项

- 禁止在 evidence_index 写入"用户说自己很厉害"这类无法核实的评价性描述；
- 禁止删除任何已有证据（只能追加或修正，修正需向用户复述原值）；
- 禁止把他人经历并入画像。
