# Upskill Planner — 技能缺口与冲刺计划

## 命令

```bash
python3 core/cli.py upskill --job <id>            # 针对某岗位
python3 core/cli.py upskill --keyword "Agent开发"  # 针对方向
```

## 引擎输出

- **缺口清单**：JD要求 × 画像证据 交叉比对（确定性同义组匹配，非LLM猜测）；
- **14/30/60天冲刺节奏**：14天只补第一缺口的基础档，**学习与投递并行，绝不停投**；
- **证据化提醒**：每条路径的终点都是"可展示的真实产出物"（代码/文档/数据），
  完成后走 /profile 回写 evidence_index，才允许出现在简历里。

## Claude 的补充职责（引擎之上的增值）

1. **缺口分级**：结合目标岗位出现频率区分「高频硬缺口」（如所有AI岗都要的RAG实操，
   优先级最高）与「低频可绕开」（单个岗位的要求，投递时用动机+学习计划话术补）；
2. **以战代练**：优先推荐"用缺口技能做与求职相关的真项目"——
   例：补前端 → 给本系统做一个投递看板页面；补数据分析 → 分析自己投递数据的转化漏斗；
3. **时间预算对齐**：问清当前课业/毕设压力，把计划压进真实可投入时长，
   给出"每周最低可行投入"，做不到的计划不如没有；
4. **进度跟踪**：用户汇报学习进展时更新计划，完成项立即提示走 profile 回写。

## 禁止

- 禁止建议"简历上先写上，边面试边学"——这是捏造，不是策略；
- 禁止生成不可执行的宏大计划（"三个月精通机器学习"式空头支票）。
