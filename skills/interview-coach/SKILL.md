# Interview Coach — 面试准备与模拟

## 命令

```bash
python3 core/cli.py interview --job <id>          # 针对岗位的题库
python3 core/cli.py interview --skills Python,LLM # 无岗位时按技能生成
```

## 题库结构（引擎生成，四板块）

1. **项目深挖**（必考）：围绕画像中与JD最相关的两段经历，STAR结构追问；
2. **技术基础**：按JD技能关键词命中生成，每题要求"概念+自己项目的例子"；
3. **行为面**：跨学科动机、团队协作（用画像里真实记载的学生工作/志愿经历作素材）、优先级管理；
4. **反问环节**：含技能缺口的主动权话术（把缺口转为学习诚意，绝不谎称精通）。

每题带 `anchor` 证据锚点与回答思路。**锚点不是装饰**：面试回答中的经历细节必须与
证据原文一致——面试官手里有你的简历，前后矛盾比经验不足更致命。

## 模拟面试流程（Claude 扮演面试官）

1. 确认目标岗位（无则用画像 target_roles 第一项）；
2. 逐题提问，每题最多追问两层（面试官真实行为）；
3. 每轮回答后给三行反馈：✅亮点（引用其真实证据）/ ⚠️风险（含糊、夸大、与证据矛盾的点）/ 📝改进句式；
4. 发现用户回答中出现画像里没有的"经历细节"→ 立即提醒：
   "这个细节目前不在你的材料里。要么走 /profile 补证据，要么换个真实说法——
   练习时编惯了，面试时就会说漏。"
5. 结束后输出总评：表达结构、高频口头禅、时间控制、3个最优先改进点。

## 面试前检查单（用户拿到 onsite/final 邀请时）

- [ ] 重新 `search --job <id>` 看技能缺口旗标，准备"缺口+学习计划"话术（/upskill 生成）
- [ ] 简历终版与话术一致性核对（greeting.md 说了的点，面试要能展开）
- [ ] 反问问题准备3个（题库第四板块）
- [ ] 线上面：设备/网络/环境；线下面：提前40分钟到
