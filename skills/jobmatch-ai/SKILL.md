# JobMatch-AI — 五维匹配评分

## 命令

```bash
python3 core/cli.py search --job <id>     # 已入库岗位：五维详情
# 即时评分（粘贴JD，不落库）：
echo '{"title":"...","company":"...","city":"南京","salary":"15-25K","description":"<JD全文>"}' \
  | python3 -c "import sys,json; from core import scorer,store; p=store.load('profile'); \
print(json.dumps(scorer.score_job(json.load(sys.stdin), p), ensure_ascii=False, indent=2))"
# 或走 MCP: tools/call score_job_text
```

## 评分体系（2027届定向，权重固定）

| 维度 | 权重 | 打分锚点（节选，完整见 core/scorer.py 常量表） |
|------|------|------|
| 技能匹配 | 35% | JD命中同义组中有画像证据支撑的比例；JD无技能词=中性50 |
| 实习/项目经历 | 25% | JD领域触发词对应画像证据标签覆盖度 |
| 地点与薪资 | 20% | 城市：期望100/远程90/其他30/未标60；薪资：达标100/不足按比例/未标60 |
| 企业与发展 | 15% | 国企央企科研院所100/知名80/一般60 |
| 专业对口 | 5% | 不限100/设计类100/计算机AI类70（跨学科有证据）/强限定20 |

- **工作年限权重=0**：要求≥1年经验的岗位在过滤层直接排除，不进评分；
- **应届生加分**（封顶+10，独立展示）：国企央企+5、落户政策+3、校招培养体系+3；
- **评级**：≥80 A·强烈推荐｜≥65 B·推荐｜≥50 C·可考虑｜<50 D·暂缓；
- **旗标**（不扣分但必须展示）：⚠️技能缺口（列明细）、薪资倒挂风险（对照城市保守参考线）、薪资未标注。

## 解释原则

- 向用户解释评分时**必须引用 reasons 里的具体依据**（"命中3/5技能组：Python/LLM/检索"），
  不许只报总分；
- 分数是确定性计算的：同输入必同输出。用户质疑分数时重跑引擎，不要口头辩解；
- 旗标永远与分数一起展示——一个92分但技能缺口三条的岗位，用户必须知道差在哪。

## 与其他系统的关系

- job-finder 用本引擎排序榜单；resume-builder 按"技能缺口旗标"决定简历侧重；
- upskill 的缺口清单就是本引擎 `dims.skill.unmatched` 的下游。
