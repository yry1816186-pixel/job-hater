## 五、已知边界（如实，不装完整）

1. Boss直聘站内半自动链路需要本地图形环境+扫码，本环境无头无法验证——状态如实标注于降级文档；
2. 部分 ATS 源（字节跳动等）列表接口不带 JD 正文，这些岗位的 `/apply` 走粘贴导入路径；
3. 语义相似度是模型相对值（非校准分），只做复核旗标不参与权重；
4. 每日自动采集未配置系统 cron（尊重用户选择，命令已就绪：`fetch --env all`）。
