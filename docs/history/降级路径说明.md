# 降级路径说明 — 每个被验证不可用/受限的方案，都有可用的退路

> 原则：反爬优先于硬刚；绝不假装成功。本文档如实记录 2026-09-20 部署当天的实测结论。

## 1. 岗位采集层

| 方案 | 实测结论 | 降级路径 |
|------|----------|----------|
| 粘贴 JD 导入 / 手动模板 | ✅ 完整验证可用（清洗→过滤→评分→简历全链路） | ——（这本身就是主路径） |
| mcp-jobs（npm v1.4.0） | ⚠️ 包真实存在（聚合猎聘/Boss/智联/51job 宣称），但实测：①包缺 `bin` 字段，README 宣称的 `npx -y mcp-jobs` 无法运行；②直接运行入口后，启动即执行演示爬取且阻塞、不响应 MCP initialize；③爬取配置过期（对智联/51job/lagou 全部 `No matching configuration`，0 结果）。已用 `mcp/wrap_stdio.js` 包装器解决 stdout 日志污染，但**上游修复前不具备实际采集能力** | 用本地 `campus-job-agent` MCP（9工具）或粘贴导入 |
| OpenHire（PyPI openhire 0.6.0） | ✅ pip 安装成功，`ohp serve` MCP 握手验证通过（对接公共 ATS 官网数据，简历不过其服务器） | —— |
| Boss直聘浏览器自动化（get_jobs 等） | ⚠️ 方案真实存在，但需本地图形环境+手机扫码，本部署环境无法验证 | 用户本地运行采集脚本→产出 JSON→ingest；或直接粘贴 |
| Playwright chromium（mcp-jobs 等依赖） | ⚠️ 本环境网络限速（~18KB/s）无法完成 ~170MB 浏览器下载 | 用户本地执行 `npx playwright install chromium` |
| 猎聘/智联/前程无忧一键采集 | 🚫 未发现当前实际可用的开源方案（调研结论） | 粘贴导入（完整功能路径） |
| 实习僧/牛客/应届生网 | 🚫 同上 | 粘贴导入；校招节点信息参考《额外引入清单》中 job-radar 等项目的信源列表，人工核对后录入 |

## 2. 真实性防线

| 防线 | 覆盖 | 局限（如实说明） |
|------|------|------------------|
| factcheck 机器闸门 | 引用覆盖/证据存在/数字溯源/高风险商业词，对抗测试 7 项全过 | **纯文字捏造**（无数字、无商业词）机器层无法识别——必须由审核Agent（LLM）逐条对照证据原文终审，两层缺一不可（skills/resume-builder 已固化此流程） |
| 审核Agent | 语义级核验（经历与证据原文的对应关系） | 依赖执行纪律；SKILL.md 已把"逐条核验"写成硬性步骤 |

## 3. 投递执行层

| 方案 | 实测结论 | 降级路径 |
|------|----------|----------|
| 全自动站内投递 | 🚫 **本系统不提供**。真实站内动作需平台浏览器会话+登录态，强行自动化违反"反爬优先于硬刚"且账号风险不可接受 | 半自动：`apply --send` 完成风控检查+本地记账，用户打开平台粘贴 `greeting.md` 发送（30秒人工动作） |
| 风控闸门 | ✅ 全部实测：每日≤25/平台、间隔≥30s、敏感时段禁投、黑名单去重（重复投递实测拦截 exit=2） | 参数可在 data/config.json 收紧（不建议放宽） |

## 4. 数据层

| 场景 | 实测行为 |
|------|----------|
| 导入文件不存在 | ✅ 友好报错 + 指引到 manual_template.json（exit=1） |
| 数据文件损坏 | ✅ 明确报错 + 备份修复指引，**绝不静默重建丢数据**（已实测） |
| 岗位库为空 | ✅ 给出补货路径提示（fetch 采集 / 手动模板导入），不崩溃 |
| 无 ≥min-score 岗位 | ✅ 提示降低阈值或补充导入 |

## 5. 网络受限环境（本次部署即在此环境）

- GitHub 大文件传输被限速至 ~18KB/s：codeload 不支持 Range 请求（断点续传实测无效），改用整包下载+多 worker 并行（见 docs/反思优化报告.md）。
- api.github.com 60次/小时限流：共享给调研 agent 使用，耗尽后以 git clone / 直接 HTTP 抓取替代验证。
- 仓库迁移：`santifer/career-ops` → `career-ops-hq/career-ops`（GitHub API "Moved Permanently" 实测发现），已按新地址拉取。
